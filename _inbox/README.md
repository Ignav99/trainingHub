# Inbox de pruebas (Visión)

Esta carpeta la lee el agente cloud. **No subas el partido entero.**

Cómo dejarnos archivos:

1. **Mejor:** arrastra el PDF o un clip de 20–60 s a este chat de Cursor. El agente lo guarda aquí.
2. Si trabajas en el repo: copia a `_inbox/` (está en `.gitignore`; no se commitea).

Sirve:

- PDF `Open-source…`
- 1–3 recortes MP4 de **vuestra cámara** (táctica/Veo o TV), 20–60 s, 720p o 1080p, &lt; 80 MB cada uno
- Un frame o nota con el color del kit nuestro

No sirve:

- El MP4 de 90 min
- Subirlo a GitHub / Render
